Políticas de Privacidade

Este termo de privacidade foi criado com o objetivo de seguir boas práticas no desenvolvimento de formulários em HTML. Nenhum dado preenchido será armazenado ou enviado para servidores externos, com exceção da consulta automática de endereço via CEP, que utiliza uma API pública.

Finalidade

Este formulário foi desenvolvido como parte do processo de aprendizado no programa de formação para pessoas com deficiência, Itaú Tech – Turma 05. Em futuras versões, o projeto será integrado a uma API RESTful que permitirá ao desenvolvedor realizar operações de cadastro, leitura, atualização e exclusão de dados — aplicando o padrão CRUD.
